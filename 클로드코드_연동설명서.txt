■ 지금 상태
  - 프로그램 코드는 GitHub 저장소에 있습니다.
      저장소: wood999-hub/ad-setup
      작업 브랜치: claude/cool-euler-nrua88  (Pull Request #1)
      https://github.com/wood999-hub/ad-setup/pull/1
  - 선생님 PC(C:\Users\PC\Documents\ad-setup)는 이 브랜치를 받아서 씁니다.
    프로그램의 [프로그램 업데이트] 버튼 = 이 브랜치의 최신 코드를 받기.
  - 저장소 안의 CLAUDE.md 에 지금까지 한 일, 결정한 것, 대화 방식이 정리돼 있어서
    새 계정의 Claude 도 자동으로 읽고 이어서 작업할 수 있습니다.


■ 1단계: (권장) 지금까지 작업을 main 에 합치기
  새 계정의 Claude 는 보통 main 브랜치에서 시작합니다. 먼저 합쳐두면 깔끔합니다.
  1. 위 PR 주소를 엽니다.
  2. 맨 아래 [Merge pull request] → [Confirm merge] 를 누릅니다.
  3. 선생님 PC 도 main 을 쓰도록 바꿉니다. PowerShell 에 붙여넣기:

     cd $env:USERPROFILE\Documents\ad-setup; git fetch origin; git checkout main; git pull

  ※ 이걸 안 하면 새 계정 Claude 가 고친 내용이 [프로그램 업데이트] 로 안 들어올 수 있습니다.
     (PC 가 옛 브랜치를 보고 있기 때문)


■ 2단계: 새 계정에 GitHub 연결
  1. 새 Claude 계정으로 https://claude.ai/code 에 로그인합니다.
  2. https://claude.ai/connect-github 에서 GitHub 를 연결합니다.
     - 저장소 주인(wood999-hub) GitHub 계정으로 연결하는 게 가장 간단합니다.
     - 다른 GitHub 계정을 쓸 거라면, 먼저 wood999-hub 계정에서
       저장소 Settings → Collaborators → [Add people] 로 그 계정을 초대하고 수락하세요.
  3. 연결 과정에서 'Claude GitHub App' 설치를 물으면
     wood999-hub/ad-setup 저장소를 선택해서 설치합니다.


■ 3단계: 새 세션 시작
  1. claude.ai/code 에서 새 세션을 만들고 저장소 wood999-hub/ad-setup 을 고릅니다.
  2. 첫 메시지로 아래를 그대로 붙여넣으세요.

     CLAUDE.md 를 먼저 읽고 이어서 작업해줘.
     내 PC 는 C:\Users\PC\Documents\ad-setup 에서 main 브랜치를 쓰고 있고,
     프로그램의 [프로그램 업데이트] 버튼으로 받아. 고친 건 main 에 반영되게 해줘.
     답은 결론 → 근거 → 검증 → 행동지침 → 지금 해야 할 것 1가지 순서로 짧게.

  3. 새 Claude 가 지금까지 상황(남은 일 포함)을 요약해 주면 연동 끝입니다.


■ 옮겨지지 않는 것 (선생님 PC 에만 있음 - 그대로 두면 됨)
  - auth 폴더  : 광고센터 로그인 정보 (절대 GitHub 에 올리거나 Claude 에게 보내지 마세요)
